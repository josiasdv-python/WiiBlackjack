What if Windows 3.1 or Windows 95 had a Blackjack game alongside their Solitaire and Hearts games?

WiiBlackjack.zip has the apps/wiiblackjack/boot.dol meant for real wii hardware. (Includes a cursor graphic)  
WiiBlackjackSource.zip has the source and assets in order to build yourself. (Includes a cursor graphic)  
WiiBlackjackDolphin.zip has a standalone .dol to run with Dolphin. (Does not include a cursor graphic)  
WiiBlackjackDolphinSource.zip has the source and assets in order to build yourself. (Does not include a cursor graphic)  

The Dolphin version is useful with default Dolphin settings on Windows/Mac/or Android.  
(On Android double tap the screen to press A)  
On Windows or Mac make sure this is ticked in Dolphin:  
"Settings/Interface/Mouse Cursor Visibility/Always" to see the operating system mouse cursor.

House Rules that benefit the Player:  
Blackjack pays 3 to 2.  
Unnatural Blackjack (after Split) pays 3 to 2.  
Suited Blackjack pays 2 to 1.  
Split allowed on any Pair.  
Any 10 value card is considered a Pair.  
Double Down on any card total.  
Double or Triple Down allowed after Split.  
Maximum Dealer or Player cards is 5.  
5 Player cards dealt without bust (Charlie)...  
wins unless Dealer has Blackjack.  
Five-Card Charlie allowed after Split.  
Five-Card Charlie pays 2 to 1.  
777 wins outright and pays 3 to 1.  

House Rules that benefit the Dealer:  
Dealer hits on Soft 17.  
$10 Min. Bet and $250 Max. Bet (Low Spread)  
Player Blackjack wins immediately unless...  
Dealer also has one, then result is a Push.  
No-Peek Table means the Dealer...  
won't check for Blackjack till Player is done.  
Split allowed only after the first deal.  
Triple Down only on Hard 9, 10, or 11.  
Double or Triple Down not allowed after Hit.  
Insurance allowed only after the first deal.  
Insurance pays 2 to 1 but costs half the Bet.  
Surrender is not allowed.
